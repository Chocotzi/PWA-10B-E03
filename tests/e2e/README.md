# Pruebas End-to-End (`tests/e2e/`)

Este directorio está reservado para las pruebas de extremo a extremo que validan el flujo crítico completo del usuario.

## Responsable asignado
- **Compañero 3** (Módulo E2E & Automatización CI)

## Casos a cubrir:
- Flujo crítico completo: Carga de PWA -> Formulario de nueva inspección sintética -> Guardado local offline -> Reconexión -> Sincronización exitosa y visualización en interfaz.
- Verificación del comportamiento sin conexión y confirmación visual al usuario.
